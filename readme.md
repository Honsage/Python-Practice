# TeamFinder

Платформа для поиска команды для работы над проектами. Пользователи публикуют проекты,
откликаются на чужие, собирают участников и ведут список избранного.

Реализован **вариант №1** задания: страница «Избранное» и фильтрация участников
по четырём критериям (авторы избранных проектов, авторы проектов, в которых я
участвую, пользователи, которым нравятся мои проекты, участники моих проектов).

## Стек

- Python 3.11, Django 5.2
- PostgreSQL
- Pillow – генерация дефолтного аватара
- SSR на штатных шаблонах Django; фронтенд (HTML/CSS/JS)

## Функциональность

- Регистрация и вход по email, смена пароля, выход.
- Профиль пользователя с автогенерируемым аватаром (первая буква имени на
  спокойном фоне), редактирование профиля.
- Валидация телефона (`8XXXXXXXXXX` / `+7XXXXXXXXXX`, нормализация и уникальность)
  и ссылок на GitHub.
- Список проектов с пагинацией, страница проекта, создание и редактирование.
- Избранное: добавление/удаление, отдельная страница владельца.
- Участие в проекте и завершение проекта (AJAX).
- Список участников с четырьмя фильтрами.
- Админка для пользователей и проектов.

## Структура

```
team_finder/   – конфигурация проекта
users/         – приложение для аутентификации и профилей
projects/      – приложение для работы с проектами
utils/         – общие утилиты (валидатор, пагинация)
templates/     – HTML-шаблоны
static/        – CSS, JS, шрифты, изображения
```

## Запуск

1. Виртуальное окружение и зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. Файл `.env` (пример в `.env_example`):
   ```
   DJANGO_SECRET_KEY=...
   DJANGO_DEBUG=True
   POSTGRES_DB=team_finder
   POSTGRES_USER=team_finder
   POSTGRES_PASSWORD=team_finder
   POSTGRES_HOST=localhost
   POSTGRES_PORT=5432
   ```

3. База данных (PostgreSQL в Docker):
   ```bash
   docker compose up -d
   ```

4. Миграции, суперпользователь, запуск:
   ```bash
   python manage.py migrate
   python manage.py createsuperuser
   python manage.py runserver
   ```

Приложение доступно на http://localhost:8000.
