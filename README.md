# Python Practice

This repo contains labs and projects that are written in order to practice development with Python programming language and Django framework. Projects can be used as code templates or study materials.

## Yandex.Practicum Projects

### Snake

*Study project* to practice OOP in Python and PyGame. It is simple implementation of classical snake game.

### Blogicum

*Study project* to practice templates, forms and ORM in Django. Represents SSR website for users' blogs.

### Yatube API

*Study project* to practice Django REST Framework, Router and JWT auth. Represents RESTful API for Yatube blog.

### Kittygram

*Study project* to practice Docker, Nginx and CI/CD around DRF backend.

### TeamFinder

*Study project* to practice full-stack Django application. It's platform of finding team for projects. 

## Other Sections

### KNN Visualizer

*Project*. Simple GUI program obviously visualizes the principle of KNN (K-nearest neighbours) method.

### Primarius Bot

*Project*. Telegram bot that sends images of cats by using external API. Just for practice TG bots.
